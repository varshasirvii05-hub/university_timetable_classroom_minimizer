University Timetable Classroom Minimizer

Greedy graph coloring assigns time slots, a greedy allocator fills and reuses rooms, and the scheduler searches for the fewest classrooms that still give a valid timetable.

How it works

  1. Input courses and rooms
  2. Create conflict graph
  3. Graph coloring
  4. Generate time slots
  5. Greedy room allocation
  6. Calculate minimum practical classrooms
  7. Validate conflicts
  8. Optimized timetable
